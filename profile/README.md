# CapexCue

CapexCue helps technical suppliers find and assess industrial and infrastructure
projects early. Our public project dossiers show what’s documented about project
scope, stage, and the organizations involved, with dated sources and gaps kept
visible. Suppliers can discover projects that fit what they sell and run commercial assessments to decide what to do next.

- [Explore public project dossiers](https://capexcue.com/projects/)
- [Try a dossier export and citation example](https://github.com/CapexCue/dossier-examples)
